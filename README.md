### Features:

- The fastest lobby loading and refreshing among lobby browsers!
- Join the lobby in-game by clicking on it
- Select 1v1 or TG to show and balance, manually override Elo, or estimate "true" Elo
- Balance for 2 - 4 teams and paste it into game chat
- Colors explain Elo:

  - Gray = no Elo in the selected leaderboard
  - Blue = estimated Elo
  - Black = actual Elo
  - Purple = manually overwritten Elo

- Make names shorter
- Open players stats

### Spectating:

- Spectate in-game with alt+click on the title while in the **spectating mode**
- Filter games by player name, map or title

### Lobbycheck:

- fantastic new feature to check the lobby settings
- intended for tournaments, community games, etc (please contact for more details)
- sharing the code just like the map/civ draft!
- future updates will include:

   - website
   - more checks
   - better code sharing
   - better interface

- the code format is a subject to change

### Bugs:

- New features could introduce new bugs, please report them!
- Starting in-game spectating doesn't work on Linux for everyone.
